# CI-PeekShield

电脑隐私防护插件，参考主流移动设备端的智能防窥体验。调用前置摄像头进行本地 AI 人脸检测，
区分主用户与偷窥人员，检测到他人窥屏时触发防窥保护（雾化遮罩 / 弹窗 / 警报 / 最小化隐私软件）。

> 所有人脸识别、人脸特征、偷窥截图均在本地完成，绝不联网上传人脸或摄像头画面。

## 功能特性

- 人脸录入：本地保存机主人脸特征，数据不出本机。
- 多人人脸识别：实时读取摄像头，区分机主 / 陌生人。
- 偷窥判定：检测到除机主外的第二张及以上人脸、且陌生人视线朝向屏幕时触发。
- 防护动作（可自定义）：桌面弹窗警告、全局雾化遮罩、扬声器提醒音、最小化受保护隐私软件。
- 受保护清单：仅查看指定软件时才触发，普通软件不触发。
- 手动防窥模式：一键固定屏幕防窥，侧面视角变暗模糊。
- 托盘常驻：悬浮查看摄像头状态与人脸数量；可关闭图标完全后台静默。
- 性能约束：空闲降帧、锁屏 / 失焦暂停、后台低占用。

## 安装教程

1. 安装运行环境：
   - Windows 10 / 11（64 位）
   - 已安装 .NET 8 桌面运行时
   - 已安装并登录 ClassIsland 2.0.x（官网：https://www.classisland.tech/）
   - 一台可用前置摄像头
2. 在 ClassIsland 插件管理器中安装本插件：
   - 方式 A：从应用内插件市场直接下载安装。
   - 方式 B：直接安装 `CI-PeekShield.cipx`（由本仓库构建产物提供）。
3. 重启或重载 ClassIsland，桌面组件出现「智能防窥」卡片即安装成功。
4. 打开插件设置页，先完成「人脸录入」，再按需配置摄像头、灵敏度与防护动作。

> 若摄像头被其他程序占用，检测将提示「摄像头不可用」，关闭占用程序后重试。

## 使用教程

1. 录入人脸（二选一）：
   - 摄像头录入：点击「录入人脸」正对摄像头保持静止约 3 秒，看到「✓ 录入成功」即可。
   - 照片录入：点击「上传照片录入」，选择一张包含你正脸的人脸照片（jpg/png/bmp），本地分析后等效完成录入，无需摄像头。
2. 选择摄像头：多摄像头电脑在「摄像头设备」下拉切换，点「测试打开」验证可用。
3. 调节灵敏度：低 / 中 / 高，控制判定偷看的距离与角度阈值（默认中）。
4. 选择防护动作：勾选弹窗、屏幕模糊、声音、最小化隐私软件。
5. 维护受保护清单：添加微信 / QQ / 浏览器 / 支付类网页等 exe 进程名；勾选「仅前台时启用」后，
   只有在查看这些软件且检测到偷窥时才会触发。
6. 静默与总控：可关闭托盘图标完全后台运行；可随时暂停全部防护或开启手动防窥。
7. 高级：设置全局快捷键一键开关智能防窥；开启偷窥截图自动保存到本地日志。

## 依赖库清单

- ClassIsland.PluginSdk 2.0.3.2（插件 SDK，版本须与主程序匹配）
- OpenCvSharp4 4.10.0.20240615（OpenCV 托管封装）
- OpenCvSharp4.runtime.win 4.10.0.20240615（OpenCV 原生运行库，已随包分发）
- 人脸识别模型：dlib ResNet-34 128 维嵌入（`shape_predictor_68_face_landmarks.dat` + `dlib_face_recognition_resnet_model_v1.dat`，已内置 Assets/Models 目录）
- .NET 8 桌面框架 / WindowsDesktop（托盘 NotifyIcon、SystemEvents、System.Drawing）
- 人脸识别基于 dlib 本地模型（68 点关键点对齐 + ResNet-34 128 维嵌入 + 欧氏距离比对），模型随插件分发、零联网、零训练
- 提醒音为本地合成（无音频文件）

## 隐私与安全

- 人脸特征模板仅保存于插件目录 `enrollment/`，日志与截图仅保存于 `logs/`。
- 不读取、不上传任何人脸、摄像头画面或账号凭证。
- 卸载插件即删除整个插件目录，本地数据一并清除。

## 已知限制

- 模板比对精度低于深度模型，极端光照 / 角度下可能误报或漏报；可在「误触抑制」中开启暗光增强与海报过滤。
- 屏幕雾化使用 Windows 模糊合成，多显示器与高 DPI 下覆盖可能存在细微边缘。
- 最小化仅作用于进程级窗口（例：最小化整个浏览器窗口），无法单独最小化某个标签页。
- 需机主先完成人脸录入，智能防窥方可区分主客；未录入时手动模式仍可用。

## 开发者构建

需在已安装 .NET 8 SDK 的环境执行：

```
dotnet build -c Release
```

产物 `bin/Release/net8.0-windows/CI-PeekShield.cipx` 即为可安装插件包。
源码采用 `net8.0-windows` TFM，因涉及摄像头 / 窗口 / 热键 / 托盘等 Windows 本机 API。
